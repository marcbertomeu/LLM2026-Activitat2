El món de la programació

La programació permet crear aplicacions, pàgines web i molts altres programes informàtics.

HTML és el llenguatge que s'utilitza per estructurar el contingut d'una pàgina web.

Una cita d'Internet

Segons la documentació de Mozilla, HTML s'utilitza per estructurar una pàgina web. Pots consultar la documentació HTML de Mozilla.

Per què aprendre a programar?

Programar ajuda a desenvolupar el pensament lògic i a resoldre problemes.

Aprendre a programar requereix pràctica.
